**原始论文**:https://arxiv.org/abs/2506.01347

## 一眼看懂
- 🟦 TL;DR:把 RLVR 的二元学习信号(对+1/错-1)拆成两条独立范式——**PSR(只奖励对的)** vs **NSR(只惩罚错的)**。惊人发现:**只惩罚错的 NSR**,在整个 Pass@k 谱(k 到 256)上一致超过基座,常追平甚至超过 PPO/GRPO;而只奖对的 PSR 提升 Pass@1 但因多样性塌缩,在大 k 处掉到基座以下。梯度分析解释:NSR 压低错 token、把概率**按模型自身先验比例**重分配给其它候选,所以"精修已有知识、不抹掉先验、改对就停手"。据此提出把正奖励降权 λ=0.1 的 **W-REINFORCE**。【原文 Abstract, §3.2, §4】
- 最巧的一步:**NSR 的 token 级梯度重分配是"按当前概率 π_v 成比例"地抬升未采样 token**(式8)。抽掉这个"按先验比例"的性质(比如换成均匀 entropy bonus),就不能保住模型先验、不能定向探索到"自己原本就觉得对"的候选,NSR 的多样性保持与 Pass@k 优势就垮了(附录 B 用梯度分析证明 entropy bonus 做不到这点)。

## 为什么做
- 研究背景:RLVR(可验证奖励 RL)用二元奖励训推理模型(DeepSeek-R1/Kimi-K1.5),既防 reward hacking 又省人工标注。但它**到底怎么用对/错样本、机理为何有效,仍未被理解**。【原文 §1, §6】
- 解决的具体痛点:多数工作只看 Pass@1/greedy 准确率,忽视了 RL 对模型行为的深层改变(尤其推理时扩展性 Pass@k)。"对样本和错样本各自起什么作用"被纠缠在一起、无法解释。【原文 §1, §2.2】
- 相关工作 & 各自不足:(1) 近期质疑 RLVR 的工作(如 Yue 2025)发现 RL 模型大 k 处反不如基座、RLVR 只是把分布挪向高奖励而非赋予新能力——本文与之一致并给出 PSR/NSR 的成因解释;(2) unlikelihood training(抑制不良生成)——本文对比指出其无 NSR 的"按先验比例重分配+改对即停"的良性性质;(3) SFT 多样性塌缩(Chu 2025)——平行现象,本文聚焦 RL 侧。【原文 §6, §4.2】
- 动机链:RLVR 有效但机理黑箱 → 把目标解析拆成 PSR+NSR 两个子目标(式2-4) → 各自单独训练 + 全 Pass@k 谱评测 → 发现 NSR 反直觉地强 → token 级梯度分析找成因 → 据此设计 W-REINFORCE(降权正奖励)。
- 与最近邻工作的Δ:相比"RL 没赋予新能力"的批评性工作,本文的 Δ 是**给出可操作的正/负信号解耦 + 梯度级机理 + 一个能同时保住 Pass@1 和 Pass@k 的简单算法(W-REINFORCE)**,把"负向信号被严重低估"这一点量化坐实。

## 怎么做 + 靠不靠谱
- 方法流水线:① 形式化:把 RLVR 期望奖励目标拆成 `L_RLVR=L_PSR+L_NSR`(式2),PSR=只对 r=+1 样本升概率、NSR=只对 r=-1 样本降概率 → ② 各自单独训练 Qwen2.5-Math-7B / Qwen3-4B / Llama-3.1-8B-Instruct,与 PPO/GRPO/REINFORCE 对比 → ③ 用 Pass@k(k∈{1..256},无偏估计式5)+ 熵/正确样本比/全解比等动态指标评测 → ④ token 级梯度分析(式7/8)解释机理 → ⑤ 提出 W-REINFORCE:`λ·L_PSR + L_NSR`,λ=0.1。【原文 §2.2, §3.1, §5】
- 逐组件必要性:
  - **PSR/NSR 解耦(核心分析工具)**:无它就回到纠缠的 RLVR,看不到两类信号的相反效应。
  - **全 Pass@k 谱评测(k 到 256)**:关键证据来源;若只看 Pass@1,会误判 PSR≈最好、完全错过 NSR 的大-k 优势与 PSR 的塌缩(Fig.2-4)。
  - **W-REINFORCE 的 λ 降权**:λ=1 即 vanilla REINFORCE(表现差);λ=0.1 取得 Pass@1 与 Pass@k 的最佳折中(Table 1)。附录 E 有 λ 消融。
  - 消融充分:有 λ 选择消融、entropy-bonus 对照(附录 B)、unlikelihood 对照、PPO/GRPO 的梯度延伸分析(§4.3)。
- 关键机制/公式(直觉,不复述符号):PSR 梯度(式7)= 抬采样到的对 token、压所有其它(含别的对候选)→ 分布越来越尖、熵塌缩、过拟合到"早期采到的对解"。NSR 梯度(式8)= 压采样到的错 token、把概率**按 π_v 比例**抬给其它候选;三个良性性质:① π_yt→1 时负梯度被 (1-π_yt) 缩小 → 不抹掉预训练学到的高置信先验(如语法);② 按先验比例软重排 → 定向探索"模型本就觉得可能对"的路径;③ 一旦不再犯该错就停止更新 → 隐式正则、**"锁住已掌握的成功经验"不再过拟合**(原文 "locking in successful experiences")。§4.3 证明 clip/KL/advantage 只改幅度不改这套方向性结论,故对 PPO/GRPO 同样适用。
- 实验与证据:数据=MATH 训练集(7500 题),verl 框架,batch 1024×8 rollout,lr 1e-6,温度 1.0;评测 MATH/AIME2025/AMC23。关键数字(Qwen2.5-Math-7B,Table 1):AIME2025 Pass@256——base 46.7、PPO 43.3、GRPO 50.0、PSR 43.3、**NSR 53.3**、**W-REINFORCE 56.7**(最高);MATH Pass@1——PPO/W-REINFORCE 并列最高 76.6,NSR 75.7,而 PSR 仅 74.1。熵动态(Fig.5b):NSR 全程维持接近基座的高熵,PSR 熵快速塌缩,PPO/GRPO 居中。**强骨干依赖**:Qwen3-4B 非思考模式下 NSR/GRPO 能激活潜在思考能力、PSR 完全失败(Fig.3);而 **Llama-3.1-8B 上所有 RL 都使大-k 退化、NSR 只是退化最少**(Fig.4)——说明结论高度依赖强先验骨干。baseline 公平(同数据/同框架/同评测协议;PSR/NSR 因只用部分样本,单 batch 有效样本更少,作者已说明)。
- 假设与失效边界:【原文】结论强烈依赖"骨干模型本身已编码强推理先验"(Qwen 系成立,Llama 系基本失效,§3.2 末、Fig.4);NSR 在小 k 处可能略弱(§5)。【推断】仅在**可验证奖励(二元对错)**任务验证(数学),开放式/带 reward model 的任务未测;只在 7B 级及以下、MATH 单数据集训练;长 CoT 的逐步信用分配未涉及(仍是序列级二元奖励)。
- 祛魅总结:【推断】真贡献=**把"负向信号(惩罚错误)"从被忽视提升为 RLVR 多样性与 Pass@k 的主要驱动力,并给出干净的梯度级机理 + 一行 λ 降权的强基线**。被高估处:W-REINFORCE 的普适性被"Qwen 强先验"撑着,换弱骨干就不灵——本质更像"**精修已有先验**"而非"教会新推理";作者自己也对齐了"RLVR 不赋予新能力"的论调。被低估处:"改对即停手 + 按先验比例重分配"是一个非常干净的"巩固而不遗忘"的机制范式,价值超出本文的数学设定。

## 结构化抽取
- 🎯 机制速览6轴:
  - 学什么信号 = 可验证的二元对错奖励;但**只用负向(惩罚错误)**那一半。
  - 改什么 = 策略模型参数(全参 RL);效果上是 token 级 logit 的定向重分配。
  - 何时改 = on-policy RL 训练期,逐 batch;NSR 仅在生成错误时更新,改对后对该样本停更。
  - 免梯度? = 否,策略梯度/REINFORCE 族。
  - 记忆-技能生命周期 = 无外部记忆;"成功经验"以"改对即停、不再扰动高置信先验"的方式隐式固化进参数。
  - 防遗忘机制 = NSR 的内禀性质:负梯度被 (1-π_yt) 缩小 → 不抹掉预训练高置信先验;改对即停 → 不过拟合已掌握样本(即一种"防遗忘/防塌缩")。

- 🎯 对"探索-巩固"对标:**强支撑 + 直接可借组件**。NSR 的三性质几乎是本课题"巩固/回轨"想要的:① "改对即停手、锁住成功经验"= 巩固而不过拟合;② "按先验比例重分配、定向探索自己觉得可能对的候选"= 探索/选路偏向"自己能走通的开头";③ "不抹掉高置信先验"= 防遗忘。**可借**:把 W-REINFORCE 的"正奖励降权 λ"思想与 on-policy 蒸馏结合——在走偏(错)处用强负向信号驱动模型自选恢复分支,而在已走通处降权/停手以固化。**缺口/竞品面**:它是纯参数级、序列级二元奖励,**没有 teacher 脚手架、没有关键步定位、没有 MTP 前瞻**;且强依赖 Qwen 先验。一句判定:NSR 提供了"巩固=改对即停 + 探索=按先验重分配"的极简机制原型,本课题需补上"teacher 稀疏接管 + 高熵分叉点定位 + MTP 探针"。
- 🔭 开放问题/未来方向:【原文】§F 讨论局限与未来:更深理解正负信号的平衡、扩展到更多任务/骨干。【推断】(1) 把序列级二元奖励升级为**关键步/分叉点级**的负向信号(只在高熵错误步惩罚),贴合 path-recovery 单点接管;(2) 验证在弱先验骨干上能否靠 teacher 蒸馏补足"先验不足"这一失效边界;(3) 与 reverse-KL on-policy 蒸馏(MiniLLM 族)融合:用教师分布定义"按谁的先验重分配",而非纯学生先验;(4) λ 的自适应调度(随掌握程度动态降权正奖励)。
