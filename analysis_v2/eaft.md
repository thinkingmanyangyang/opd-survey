## 一眼看懂
- 🟦 TL;DR：SFT 之所以损害通用能力，主因不是"训练流程"本身，而是一类特定 token——**模型自己很笃定(低熵)、标签却逼它输出另一个 token(低概率)**，论文叫它"Confident Conflict(自信冲突)"。EAFT 用**每个 token 的归一化熵**当门控系数去缩放交叉熵损失：模型越笃定(熵越低)梯度越被压到接近 0，越不确定(熵越高)越退化为普通 SFT。只换一个损失函数，不引入 RL、不加额外模型，就把遗忘缩到约 SFT 的 1/4~1/5,同时目标任务不掉分。【原文 §Abstract/§3.3/Eq.2-3】
- 最巧的一步：**把门控信号从"概率"换成"熵"**。抽掉这一步(退回到看概率，即 DFT/FLOW 那套)方法就垮——因为低概率 token 有两种来源：(a) 模型真不会、该学(epistemic uncertainty，此时熵也高)；(b) 模型很有把握想输出别的、标签相悖(Confident Conflict，此时熵低)。只看概率会把这两类一视同仁，甚至在 (b) 上**放大**破坏性梯度、加速遗忘；熵恰好能把"该学(高熵)"和"该抑制(低熵)"分开。【原文 §2 末/§3.2/§1】

## 为什么做
- 研究背景：SFT 是把通用 LLM 适配到数学/医疗/Agent 垂直域的标准做法，但常伴随灾难性遗忘("Alignment Tax")；近期对照工作(Chu et al. 2025"SFT memorizes, RL generalizes"；Shenfeld et al. 2025 RL's Razor；Chen et al. 2025"Retaining by doing")反复观察到 **on-policy RL 适配目标任务时对通用能力损害远小于 SFT**。【原文 §1/§2】
- 解决的具体痛点："为什么 SFT 频繁损害通用能力、而 on-policy RL 能保住?"——论文要给出机理级解释并据此改 SFT。【原文 §1，斜体设问】
- 相关工作 & 各自不足：
  - **KL 正则(SFT-KL / RL's Razor)**：约束新模型不偏离原分布——但粗粒度，既压有害更新也压有益学习，常得不偿失。【原文 §2/§4.2 Table 1 SFTKL】
  - **基于概率的 token 重加权(DFT 重加权 loss、TALR 动态学习率、FLOW 上采样易样本)**：思路是"模型已会的少学、不会的多学"——但只看概率不足以判断该不该学，在 Confident Conflict 上反而放大破坏性梯度。【原文 §2 末段/§1】
  - 灾难性遗忘的经典思路(EWC、LwF、GEM 等约束参数变化)被列为远端背景。【原文 §2】
- 动机链：现状(SFT 适配必伴遗忘，RL 不会)→ 诊断(系统统计训练数据逐 token 概率×熵，发现 SFT 数据比 on-policy rollout 多出一簇"低熵+低概率"token，Fig.1b)→ 归因(pilot study：单纯**屏蔽**这些 token 的 loss 就几乎消除遗忘，Fig.2a)→ 所以(遗忘主因是"在冲突样本上被迫做大梯度更新"，而非 SFT 流程)→ 用连续熵门控替代硬屏蔽(后者丢数据+依赖敏感阈值 τ,δ)。【原文 §3.2/§3.3】
- 与最近邻工作的 Δ：相对 **DFT**(同为"乘一个 token 级系数到 CE 上"的单行改动)——DFT 乘的是**预测概率**(detach)，EAFT 乘的是**归一化熵**。差在：概率无法区分"低概率因为不会"vs"低概率因为相悖"，熵可以。论文还把 DFT 列为基线，且在其主表里 DFT 的遗忘缓解效果常差于甚至不如 SFT(如 GLM4-9B 上 DFT General Avg -8.4 反而比 SFT 的 -6.0 更糟)。【原文 §2/Table 1】

## 怎么做 + 靠不靠谱
- 方法流水线：输入(标准 SFT 数据 {(x,y)}) → 前向得每个 target token 的预测分布 → 在 **Top-20** 概率上算熵 H_top-20 → 归一化 H̃_t = H_top-20 / ln(20)≈/3.0 ∈[0,1] → loss = −Σ_t H̃_t · log P_θ(y_t|x,y_<t) → 反向更新。输出：一个目标域适配、但通用能力几乎不退的模型。【原文 Eq.2/Eq.3】
- 逐组件必要性：
  - **熵门控(核心)**：没它就退回普通 CE，遗忘照旧。§5.1 把门控泛化为 f(H̃)，测了线性、二/三次幂(EAFT2/3)、Sigmoid(β=0.17,α=30)与硬屏蔽(Masked SFT)——**所有"熵感知"变体都比 SFT 保住更多通用能力**(说明增益来自"看熵"这一机制本身，而非具体函数形式)；这是一个相当强的消融，证明结论不依赖某个魔数。【原文 §5.1/Fig.5】
  - **软门控 vs 硬屏蔽**：硬屏蔽虽防遗忘，但目标 Math Score 掉到 65.60(EAFT 69.27)——说明"自信冲突"里其实**也含必要的适配信号**，一刀切会连有用的也丢；软门控只降权不删，占住 Pareto 前沿。这一对比直接论证了"为什么不能简单屏蔽"。【原文 §5.1 The Necessity of Soft Gating/Fig.5】
  - **Top-K 近似(K=20)**：为省全词表(|V|>100k)算熵的开销。§5.2 显示 Top-20 与精确熵 Pearson 相关 0.999、额外显存 <0.4KB——近似几乎无损，有定量曲线支撑(Fig.6)。【原文 §5.2/Fig.6】
- 关键机制/公式(直觉)：CE loss 对"低概率 token"天然给最大梯度(要把概率从很低拉高，需要大幅更新参数)；在低熵处这种大更新会**改写**承载通用能力的表征(Fig.3 梯度热图左下角深色)。乘上 H̃_t 后，低熵→系数≈0→把这股大梯度压灭(Fig.3 右图同区域变浅黄)；高熵→系数≈1→正常学。直觉就是"按模型自身的不确定度决定该不该被标签'掰过来'"。【原文 §3.2 Theoretical Insight/§4.3/Fig.3-4】
- 实验与证据：
  - 数据：prompt 取自 NuminaMath / BigMathVerified / Nemotron-CrossThink，用 Qwen3-235B-A22B-Instruct 合成回答，随机选 **19k 条被验证正确**的样本作数学训练集；医疗用 Huatuo-O1，Agent 用 Nemotron-Agentic-Tool-Use-v1 子集。【原文 §4.1/§4.4】
  - 模型：Qwen3-4B-Instruct、Qwen2.5-32B-Instruct、GLM4-9B-0414(4B–32B 跨族跨规模)；医疗用 Qwen3-4B-Thinking。【原文 §4.1】
  - 关键数字(Table 1，Qwen3-4B-Instruct 数学域)：SFT 把 Math Avg 68.3→69.4，但 General Avg 81.1→**76.5(-4.6)**；EAFT Math Avg 69.3(与 SFT 几乎并列)、General Avg **80.1(仅 -1.0)**；其中 CLUEWSC：SFT 从 85.2 掉到 74.5(-10.7)，EAFT 仅到 83.7。32B 上 SFT -3.2 vs EAFT -1.1;GLM4-9B 上 SFT -6.0 vs EAFT -3.9。跨域：医疗 SFT -4.8 vs EAFT -1.6(且 EAFT 目标 73.7 略超 SFT 73.6)；Agent SFT -6.3 vs EAFT -3.6。【原文 Table 1/2/3】
  - baseline 公平吗：基线(SFT/SFTKL/FLOW/DFT/TALR)同数据同评测，三次独立 run 取均值——较规范。值得注意 DFT/TALR 在多处遗忘缓解效果差于 SFT 本身，凸显"概率门控未必防遗忘"。【原文 Table 1】
  - 有无"看着强但没回答核心问题"：核心问题是"减遗忘"，主战果都在 General Avg 的下降幅度上(目标分基本与 SFT 持平、个别略低如 Qwen3-4B AIME24 EAFT 60.0 < SFT 63.3)。它**不主张**超越 SFT 的目标性能，定位是 Pareto 改进。【原文 §7 Target Performance Trade-off】
- 假设与失效边界：
  - 【原文】§7 明确三条失效边界：① **反事实/知识编辑场景**(如要教模型"天是绿的"、纠正过时事实)——此时正需要覆盖先验，EAFT 会把这些必要更新当冲突压掉，**适得其反**；② EAFT **不以超越 SFT 目标分为目标**，纯追目标性能时 SFT 仍可能更优；③ **依赖 base 模型校准**——若 base"自信地错"(幻觉)，EAFT 会**保护这些错误**先验，不去纠。
  - 【推断】门控只看模型**自身**的熵，并不直接判断"标签是否真与模型相悖"：低熵但标签恰好一致的 token 也被同等降权，理论上可能轻微拖慢一部分正确知识的快速拟合(论文用 Fig.4"高熵 token loss 下降与 SFT 同速"间接回应，但未对"低熵且一致"的 token 单列分析)。依据：Eq.2 门控仅是 H̃_t 的函数，与 ground-truth 是否冲突无关。
- 祛魅总结【推断】：
  - 真贡献：把"SFT 伤通用能力"的归因从模糊的"过拟合"收敛到一个**可操作、可视化、可消融**的具体对象(低熵+低概率 token)，并给出极简且对函数形式鲁棒的修法——诊断(Fig.1/2)→机制(Fig.3/4)→方法(Eq.2)→鲁棒性(Fig.5)的闭环相当完整，是其分量所在。
  - 包装/可能被高估："用熵当门控"本质是**置信度加权的另一种形式**——与 DFT 的"概率加权"是同一族(forward-hard / backward-soft 式的"按某统计量重加权 CE")，区别在选了"熵"这个更能分离冲突的统计量。所谓"自信冲突"很大程度等价于"模型先验与标签强不一致的 token"这一已知现象的命名化。它解决的是"适配时少忘"，**并未**让 SFT 学得更多/更好(目标分不升)。

## 结构化抽取
- 🎯 机制速览6轴：
  - **学什么信号**：每个 target token 的**预测熵**(Top-20 近似全词表熵)，作为"该不该被标签掰过来"的门控；不学奖励、不学教师 logits。
  - **改什么**：只改**损失函数**(CE 前乘 H̃_t)；模型/数据/优化器/流程与全参 SFT 完全一致。
  - **何时改**：训练时(每步前向算熵→当步缩放 loss)；推理时无任何改动。
  - **免梯度?**：是 SFT 范式、无 RL rollout、无策略梯度。〔待核：门控系数 H̃_t 是否对其自身 stop-gradient(detach)。Eq.2/Eq.3 与正文均未显式写 detach；从"熵由当前 P_θ 算出、且是 loss 的乘性系数"看，若不 detach 则梯度会经熵项回流(等价于额外鼓励/抑制熵)。同族 DFT 明确 detach 概率系数，EAFT 论文未明示，需以集成实现(LlamaFactory-EAFT 的 use_eaft_loss 损失代码)为准——本地未克隆该 fork，无法审计。〕
  - **记忆-技能生命周期**：属"**巩固时防遗忘**"——把新技能(目标域)写进参数的同时，靠抑制低熵冲突梯度来**保护旧表征**；无显式外部记忆/技能库，纯参数内做。
  - **防遗忘机制**：核心即此——熵门控对"低熵冲突"token 近零梯度(Fig.3)、对低熵 token loss 全程保持稳定不被推向 0(Fig.4)，从而不改写通用表征。与 KL 正则(约束输出分布)不同，它是**逐 token 门控梯度尺度**。
- ⑦ 开源代码+框架/harness：主仓库 https://github.com/PRIS-CV/EAFT (README+assets，无独立训练代码)；项目页 ymxyll.github.io/EAFT/。**实现集成**进 LLaMA-Factory(官方合入，`use_eaft_loss` 启用；作者分支 github.com/ymxyll/LlamaFactory-EAFT)与 ms-swift(github.com/ymxyll/ms-swift-EAFT，支持 megatron/deepspeed)。框架=标准全参/SFT(DeepSpeed/Megatron/FSDP2/LoRA)，仅替换损失，无 RL、无额外模型。【代码可得性中等：主仓无核心代码；v1 记录本地 `resource/repos/eaft/` 下两个 submodule 目录为空(指针未拉取)，**损失实现无法本地审计**，需到上述 fork 查看——此为"未完整克隆"，链接已附。】
- 💰 资源/成本与可扩展性：训练成本 ≈ 标准 SFT(只多算一次 Top-20 熵)；§5.2 实测 Top-20 额外显存 <0.4KB、几乎无额外开销。规模验证到 32B、跨 Qwen3/Qwen2.5/GLM4。数据量小(数学 19k)。【原文 §5.2/§4.1】
- 🎯 对"探索-巩固"对标：**强支撑(巩固/防遗忘侧)+ 弱竞品(探索侧无)**。判定依据：本课题的"巩固"= 把有效行为固化进参数且不遗忘——EAFT 正是"巩固时不遗忘"的一个干净机制；且它对"熵=探索信号"的用法与本课题"高熵=分支/选路点、低熵=笃定"的直觉**高度同构**(§AppA 词云：高熵 token=推理分支点/连接词，低熵=语法/固定模式，自信冲突=长尾实体/噪声)。**可借组件**：用归一化 Top-K 熵做逐 token 门控，可直接迁移到 MTP/OPD 的"巩固"损失上，对"模型已笃定走通的开头/路径"降权、对"高熵需探索处"保权，实现"固化新技能而不冲掉旧能力"。**缺口**：①EAFT 是离线 SFT，未结合 on-policy/student-自选(本课题要 on-policy 自选恢复分支)；②无"回轨/path-recovery"的探索机制，只防遗忘不主动选路；③门控只看自身熵、不看"是否真冲突"，与"teacher 当稀疏脚手架"无对接。
- 🔭 开放问题/未来方向：
  - 【原文 §7】结合**不确定性校准**以区分"真知识 vs 自信幻觉"(否则会保护错误先验)；明确 EAFT 不适用于知识编辑/反事实训练。
  - 【推断】把熵门控嵌入 on-policy 蒸馏/RL 的巩固阶段(而非纯离线 SFT)，让"探索(高熵处学)+巩固(低熵冲突处稳)"在同一回路里成立；以及对"低熵且标签一致"token 是否被过度降权做专门消融。
