## 一眼看懂

> 一句话导读:学界在吵"RL 到底是教会模型新本事,还是只把它本来就会的高分答案放大";本文给出一套能跑 2000+ 步不崩的长程 RL 配方,在 base 完全做不出的任务上把准确率从 0 拉到满分,论证 RL 确能扩展推理边界——但有前提。

- 🟦 TL;DR:学界争论的核心是——RL 到底是发现新的推理能力,还是只放大 base 模型已潜在的高奖励输出?(后一种观点由 Yue/Dang/Zhao 等人用 pass@k 来论证;pass@k 指采样 k 次里至少答对一次的概率,k 越大越能看出模型潜在的解题上限。)
  - 本文用一套能跑 **2k+ 步不崩**的长程 RL 配方,在 **136K 五域可验证数据**上训练。配方记作 ProRL,组成如下:
    - GRPO 打底;
    - 叠 DAPO 的两个组件:解耦 clip + 动态采样;
    - 加 KL 正则;
    - **周期性把参考策略硬重置为近期的在线快照**。
  - 证据:在 base 即使大量采样(pass@128 / 256)也完全做不出的任务上(boxnet:base 的 pass@k 全是 0.000,RL 模型达到 1.000),RL 之后能做对。由此主张 RL **确能扩展**推理边界,而非仅放大——但前提是足够长的训练 + 良好初始化 + base 本来就弱的领域。
  - 产出 **Nemotron-Research-Reasoning-Qwen-1.5B**(号称当时最强的 1.5B 推理模型)。【原文 Abstract 行 14-34,§4.2-4.3,Figure 4-5,Table 3】
- 最巧的一步:**参考策略硬重置(Reference Policy Reset)**。
  - 为什么关键:抽掉它,长程 RL 会卡死。随训练推进,KL 项会**逐渐主导损失**,policy 更新越来越小,过早收敛。
  - 怎么做:周期性把参考策略 \(\pi_{\text{ref}}\) 硬重置为近期的在线快照 \(\pi_\theta\),并重置优化器状态,就能"在保留 KL 稳定收益的同时持续提升"。
  - 它和"保留 KL"是一对:单留 KL 会停滞,单去 KL(DAPO/ORZ 的主流做法)会熵坍缩(熵=输出分布的多样性,坍缩=分布过早变尖、不再探索);ProRL 用"KL + 定期重置"把两者的好处都拿到。【原文 §2.3.1 行 223-228】
  - 注:这是**机制层面**的命门(论文用训练曲线 + 直觉来论证),但论文**没做"逐组件剥离"消融**(没有 w/o reset / w/o KL 的对照实验),所以"最巧一步"的因果强度部分依赖叙述、而非受控实验。【推断:全文无 ablation 表】

## 为什么做

> 一句话导读:之前说"RL 不扩展能力"的研究,本文认为是栽在两个方法论坑里——只测了数学(本就被过度训练)、且训练太短;所以它要换长程 + 多域 + 稳定化的配方重新验证。

- 研究背景:o1 / DeepSeek-R1 等推理模型靠 test-time scaling(推理期扩展算力,即长 CoT + 探索/验证/回溯)在数学/代码上大幅提升。RLVR(针对可验证奖励的 RL)是核心驱动力,且能缓解 reward hacking(模型钻奖励空子)。【原文 §1 行 37-47】
- 解决的具体痛点:
  - ① 流行观点(Yue et al.[13]、Dang et al.[14]、Zhao et al.[15])认为 RL 不带来超越 base 的新能力,只放大已潜在的输出——base 大量采样仍做不出的题,RL 后也做不出。
  - ② 长程 RL 会遇到**熵坍缩**与不稳定:输出分布过早变尖、熵骤降、探索受限;而 GRPO 的学习信号**依赖一组多样采样**来估相对优势,熵一坍缩,更新就偏置、训练停滞。
  - ③ 单纯提高采样温度只能**延缓**、而非阻止熵坍缩(论文实测,行 188-190)。【原文 §1 行 104-114,§2.2.1 行 182-190】
- 相关工作 & 各自不足(精确到论点):
  - **[13] Yue et al.**——用 pass@k 论证 RLVR 不扩展能力(甚至退化)。本文反驳其**两个方法论局限**:(1) 过度依赖**数学**这种"预训练 + 后训练都被过度训练"的领域,探索空间本就被压缩了;(2) RL 步数太短(通常 <几百步,行 114),模型还没充分探索就停了。
  - **[14] Dang et al.**——推导 pass@k 上界,并观察到训练中 pass@k 下降。
  - **[15] Zhao et al.("Echo chamber",回音室)**——RL 收敛到主导分布、只放大预训练模式。
  - **去 KL 阵营 [4,7,5,18]（DAPO/ORZ 等）**——主张移除 KL,理由是 CoT 任务里模型训练中会"自然发散"。本文的观察是:**这一观点多适用于未经 SFT 的 base 模型**;而 ProRL 从**已 SFT、能产出连贯 CoT 的良好起点**(DeepSeek-R1-Distill-Qwen-1.5B)出发,此时保留 KL 对稳定与持续熵仍然有益(行 218-222)。
  - 关键差异:本文不只改 clip/归一化,而是把"**长程 + 多域 + 稳定化(KL + 重置)+ 良好起点**"四者绑定,并用两个更强的证据来区分"扩展 vs 放大":
    - **Creativity Index**——轨迹与预训练语料 DOLMA 的重叠度,越低=越新;
    - **base 全 0 任务上 RL 做对**——直接证明能力是新涌现的。
- 动机链(为什么这样设计):
  - 质疑"RL 不扩展能力"这个假设;
  - 怀疑那其实是"领域过窄 + 训练过短"两个方法论缺陷造成的假象;
  - 于是设计能长跑(2k+ 步)且覆盖五域(数学/代码/STEM/逻辑谜题 Reasoning Gym/指令遵循)的 ProRL,并用稳定化压住熵坍缩;
  - 最后验证"扩展边界"与 base 任务能力、训练时长强相关。【原文 §1 行 115-126】
- 与最近邻工作的Δ:
  - vs DAPO/ORZ 等"去 KL"主流——ProRL **反其道保留 KL**,并把适用前提**条件化**("要从已能产连贯 CoT 的良好初始化出发"才保 KL);又新增**参考策略重置**,解决"KL 项后期主导→更新停滞"的问题。
  - vs [13/14/15]——用 Creativity Index + base 全 0 任务 RL 做对,作为"扩展"的更强证据;且诚实给出边界:"只在 base 弱的领域扩展,base 强的领域 pass@128 反而下降"。

## 怎么做 + 靠不靠谱

> 一句话导读:配方是四层叠加——GRPO 打底,加 DAPO 的解耦 clip + 动态采样防熵坍缩,加 KL 正则防漂移,再加"参考策略硬重置"解决 KL 后期把更新拽死的问题;但全文没有受控消融,各组件贡献只能靠机制论证。

- 方法流水线(§2,讲清输入→输出):
  - **输入**:良好初始化的 base \(\pi_\theta\)(DeepSeek-R1-Distill-Qwen-1.5B,已能产连贯 CoT);136K 五域可验证数据(每域配二值或连续奖励)。
  - **输出**:Nemotron-Research-Reasoning-Qwen-1.5B,一个跨域 generalist(通才模型)。
  - **① 基座 GRPO(去掉 critic)**:
    \(\displaystyle L_{\text{GRPO}}(\theta)=\mathbb{E}_{\tau\sim\pi_\theta}\!\left[\min\!\Big(r_\theta(\tau)A(\tau),\ \operatorname{clip}(r_\theta(\tau),1-\epsilon,1+\epsilon)A(\tau)\Big)\right],\quad r_\theta(\tau)=\frac{\pi_\theta(\tau)}{\pi_{\text{old}}(\tau)}\)
    优势用组内标准化(从而省掉 PPO 的 critic 网络):\(A(\tau)=\dfrac{R_\tau-\operatorname{mean}(\{R_i\}_{i\in G(\tau)})}{\operatorname{std}(\{R_i\}_{i\in G(\tau)})}\)(Eq.2)。
  - **② 叠 DAPO 的两个组件**(§2.3,目的是抗熵坍缩):
    - **解耦 clip**(Eq.3):把 clip 的上下界拆成两个独立超参 \(\operatorname{clip}(r_\theta(\tau),1-\epsilon_{\text{low}},1+\epsilon_{\text{high}})\)。调高 \(\epsilon_{\text{high}}\) 叫 "clip-higher",作用是**抬升低概率 token 的上行空间**、保住熵、减少 mode collapse(模式坍缩)。实测有效(行 200-202)。本文取 \(\epsilon_{\text{low}}=0.2,\ \epsilon_{\text{high}}=0.4\)。
    - **动态采样**:过滤掉 acc=0 或 1 的 prompt(全错或全对都没学习信号),聚焦中等难度,维持多样的学习信号。
  - **③ 叠 KL 正则**(Eq.4):\(L_{\text{KL-RL}}(\theta)=L_{\text{GRPO}}(\theta)-\beta\,D_{\text{KL}}(\pi_\theta\,\|\,\pi_{\text{ref}})\)。它有三重作用:维持熵、防止在线 policy 偏离稳定参考太远、**抑制对 spurious reward(虚假奖励信号)的过拟合**(行 215-217)。
  - **④ 参考策略硬重置**(§2.3.1):当验证集(blended validation,混合验证)停滞或退化时,把参考策略更新成近期在线 \(\pi_\theta\) 的快照(\(\pi_{\text{ref}}\leftarrow\) 该快照),并**重置优化器状态**。全程反复应用,避免过早收敛、鼓励长训练。
  - **数据流动 / 何时重置**:用从评测基准混出来的 validation set 监控;性能一停滞就触发硬重置(既恢复稳定性,又**促使 policy 进一步偏离 base**,行 261-263)。多数训练的 response 上限 8k token,**末段提到 16k**(行 264+)。
- 逐组件必要性:**全文没有受控 ablation 表**。各组件的必要性靠"机制论证 + 训练曲线"支撑:
  - 温度只**延缓**熵坍缩(行 188-190,实测论证;且仍用高温 1.2 来抬高初始熵);
  - clip-higher 保熵(行 200-202,观察);
  - KL 保熵 + 防漂移 + 抑制 spurious-reward 过拟合(行 215-217);
  - 重置防"KL 后期主导→更新趋零→停滞"(行 223-228)。
  - **没有"去掉某个组件后掉多少分"的对照实验**——这是方法学上的明显短板:无法定量归因"重置" vs "仅 KL" vs "仅 DAPO"三者各自的边际贡献。【推断:全文 grep 无 ablation / 无 w/o reset 实验】
- 关键机制/公式(直觉):
  - 核心张力=**熵坍缩 vs 探索预算**。拆开看:
    - GRPO 需要一组多样采样才能估好相对优势 \(A(\tau)\),一旦熵坍缩(分布变尖),它就退化成偏置更新、停滞;
    - clip-higher 给低概率 token 更大的上行空间(保探索);
    - KL 把策略**拴在稳定参考**附近(防崩);
    - 但 KL 久了会"拽太紧"(\(\beta D_{\text{KL}}\) 项主导),使更新趋零;
    - **重置 = 松开缰绳再系到新位置**(参考策略跟进 + 优化器清零),所以能"长跑且不早收敛"。
  - **pass@k 上界**(引 Dang et al.):该上界随期望 pass@1 升高、随其方差降低。ProRL 把整体分布**右移**(pass@1 提升),足以盖过"分布变尖→方差变化"的负效应,从而在多数复杂任务上 pass@128 也跟着升;但**数学等 base 已饱和的领域**是例外(见下文"诚实反例")。
- 实验与证据:
  - 数据集/设置:
    - 数据=自构 **136K** 可验证问题(数学/代码/STEM/逻辑谜题 Reasoning Gym/指令遵循,每类配二值或连续奖励,组成见 Appendix D);
    - 基座=**DeepSeek-R1-Distill-Qwen-1.5B**;框架=**veRL**;
    - 超参:\(\epsilon_{\text{low}}=0.2,\ \epsilon_{\text{high}}=0.4\)、动态采样过滤 acc∈{0,1}、每 prompt **n=16**、context 8096、**温度 1.2**、**batch 256 / mini-batch 64**(每次 rollout 做 4 次梯度更新)、AdamW 常数 lr **2×10⁻⁶**;
    - 算力=**4×8 H100-80GB**,约 **16k GPU·小时**;多数训练 response 上限 8k,末段提到 16k。【§3.2 行 250-257】
  - 关键数字 — **增益数值有两套口径(论文内部不一致,这里并列记录)**:
    - **§1(行 123-124)**:数学 **+14.7%**、代码 **+13.9%**、逻辑 **+54.8%**、STEM **+25.1%**、指令 **+18.1%**。
    - **§3(行 236-237)**:数学 **+15.7%**、代码 **+14.4%**、STEM **+25.9%**、指令 **+22.0%**、逻辑 **+54.8%**;并超过领域专用基线(数学 +4.6%、代码 +6.5%)。
    - 两套差异主要在指令(18.1% vs 22.0%)、数学(14.7% vs 15.7%)、STEM/代码;**原因论文未说明**,本分析以 §3/结果节为准(与 Table 对应)。【已核行 123-124 vs 236-237】〔待核:两套口径差异原文无解释〕
  - **边界扩展最强证据(Figure 5,boxnet OOD)**:base 的 pass@k 在 k=1,2,4,…,256 上**全为 0.000**;RL 模型 final 达到 **1.000**(中间 checkpoint 0.994@128→1.000@256),且 final 在所有 k 上都一致 ≥ intermediate(行 1032-1062)。Table 3 数值:base boxnet **0.00**、R1-7B 1.71、Nemotron-1.5B 远超(行 363-379)。
  - **三 regime(Figure 4,关键诚实反例)**——RL 的效果分三种区间:
    - (1) **Diminished(退化)**:部分**数学**基准 pass@1 升、但 **pass@128 反降**。原因是 base 本就强,RL 只是把分布变尖、牺牲了多样性,与 [13] 的结论一致(行 992-997)。
    - (2) **Plateau(平台)**:pass@1 和 pass@128 都升,但**早期就饱和**,ProRL 多跑的步数收益很小(行 1000-1003)。
    - (3) **Sustained(持续)**:复杂任务(如 coding)随长训练持续提升,真正扩展边界(行 1004-1008)。
    - 即**ProRL 并非到处都能扩展边界**,只在 base 弱的复杂任务上扩展。§4.2(行 517-527)进一步指出:边界扩展(pass@128)与 base 的初始能力**负相关**——base 高 pass@128 的任务,RL 后边界反而收窄/负增益;base 低 pass@128 的任务,RL 最有效。
  - **新颖性证据**:Creativity Index(对 DOLMA 语料的非重叠度)随训练上升 **3.84→4.42→4.70**(Figure 1 中);base 已熟悉的任务 creativity 低(行 530-535)。
  - baseline 公平性:与同 base(R1-Distill-1.5B)以及领域专用基线(DeepScaleR、DeepCoder 等)对比,并提供 R1-7B 作灰色参考,较公平;但**仅 1.5B 单规模、单 base**。
  - 看着强但没回答的:
    - ① 全程**无组件消融**,稳定化各组件的贡献无法定量归因;
    - ② "扩展边界"的判定高度依赖 pass@128 与 Creativity Index 两个测度(pass@k 对 k/温度敏感,Creativity Index 只是语料重叠的代理);
    - ③ §1 vs §3 增益数值不一致。
- 假设与失效边界:
  - 【原文】① 适用前提=要从"良好初始化(已蒸馏、能产连贯 CoT)的起点"出发,直接对 base 模型做 RL 不在此列(行 218-222)。
  - 【原文】② 边界扩展只在 base 初始弱的领域显著;base 强的领域反而 pass@128 退化(Figure 3/4,§4.2)。
  - 【原文】③ KL 项后期会主导→所以需要重置(行 223-224)。
  - 【推断】④ 仅验证了 1.5B、单一 base;更大模型/不同起点的可迁移性未验证。
  - 【推断】⑤ "扩展 vs 放大"结论的强度依赖 pass@128(大 k)与 Creativity Index 的稳健性,换测度可能动摇定性结论。
  - 【推断】⑥ 16k GPU·hr 成本对小团队复现门槛高,且无训练代码、需自行在 veRL 上拼装。
- 祛魅总结:【推断】
  - 真贡献=① 以**强反例**(boxnet base 全 0、RL 满分)+ Creativity Index,把"RL 能扩展边界"从口号变成可观测现象,并诚实给出边界条件("只在 base 弱领域有效,且分 Diminished/Plateau/Sustained 三态");② "KL + 参考重置"是一套长程 RL 的实用稳定化配方。
  - 被高估处:标题"Prolonged RL Expands Reasoning Boundaries"偏强——实证里数学等领域 pass@128 反降,普适性被三 regime 打了折;且"扩展边界"对测度敏感。
  - 被低估处:对"去 KL 是否普适"的细致反驳(**限定在良好初始化的前提下**),其实调和了 ORZ/DAPO 的对立主张,这一**前提条件化**的洞见比标题更有价值。
  - **数值一致性瑕疵**:§1(行 123-124)vs §3(行 236-237)两套增益数不同,原因论文未说明,本分析采 §3。

## 结构化抽取
- 🎯 机制速览6轴:
  - **学什么信号**:可验证结果奖励(二值/连续,跨数学/代码/STEM/逻辑/指令五域),GRPO 组内归一优势 \(A(\tau)\);无 teacher/无 KD。
  - **改什么**:policy 参数 \(\theta\)(GRPO 梯度);参考策略 \(\pi_{\text{ref}}\) 周期性被硬重置(非梯度,是 copy 快照 + 重置优化器)。
  - **何时改**:纯在线 on-policy RL,长达 2k+ 步;重置由 blended validation 停滞触发。
  - **免梯度?**:否,policy 全程梯度更新。
  - **记忆-技能生命周期**:无外部记忆/技能库;多域"技能"通过长程 RL 固化进单一 generalist 参数;\(\pi_{\text{ref}}\) 重置=滚动更新"稳定锚点"。
  - **防遗忘机制**:**KL-to-reference 正则(Eq.4)是核心稳定/防漂移手段**(防偏离稳定参考、抑制对 spurious reward 过拟合);参考重置避免 KL 拽死。这是"防(过快)漂移/防熵坍缩"而非"跨任务防遗忘";多域联合训练间接缓解单域过拟合。
